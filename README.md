# 🩻 ComputerVision-XRay-Classification

An Image Processing and Computer Vision (IPCV) project using chest X-ray images.

## 🎯 Objective
Classify chest X-ray images into four categories:
- COVID
- Lung Opacity
- Normal
- Viral Pneumonia

## 🛠️ Technologies
- Python
- Google Colab
- Image Processing and Computer Vision libraries

## 📓 Project Notebook
`IPCV_CAT2.ipynb`

## ⚠️ Disclaimer
This project is for educational purposes only and is not intended for medical diagnosis.
